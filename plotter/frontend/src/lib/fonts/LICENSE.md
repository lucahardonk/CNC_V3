# Font a tratto singolo

I file JSON in questa cartella sono generati da `scripts/build_fonts.py` a partire dai font SVG
del pacchetto npm [`hersheytext`](https://github.com/techninja/hersheytext) (MIT, © James T),
che include le conversioni di Windell H. Oskay / Evil Mad Scientist:

  ("The Hershey Fonts are a set of vector fonts with a liberal license").
- **EMS fonts** (Allure, Readability, Tech, Felix, Nixish, …): SIL Open Font License 1.1.
